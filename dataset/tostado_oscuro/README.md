# Clase: `tostado_oscuro`

Coloca aquí las imágenes de granos con **tostado oscuro** (dark roast):
marrón muy oscuro casi negro, superficie **brillante/aceitosa**, aroma amargo/ahumado.

- **Mínimo 30 imágenes.**
- Varía la **iluminación** (luz natural, luz cálida, sombra).
- Varía el **fondo** (mesa clara, mesa oscura, mano, tela).
- Varía el **ángulo** y la **distancia**.

> ⚠️ El brillo aceitoso puede generar reflejos según la luz. Captura ejemplos
> con y sin reflejos para que el modelo no aprenda a depender del brillo del flash.
