# Clase: `verde` (café sin tostar)

Coloca aquí las imágenes de **granos de café verde**, es decir, café pergamino/almendra
**antes de tostar**. Color verdoso, grisáceo o amarillento pálido.

- **Mínimo 30 imágenes.**
- Varía la **iluminación** (luz natural, luz cálida, sombra).
- Varía el **fondo** (mesa clara, mesa oscura, mano, tela).
- Varía el **ángulo** y la **distancia** (cerca, lejos, cenital, inclinado).
- Evita que aparezcan otros objetos que confundan al modelo.

> Estas imágenes NO se versionan si activas la regla del `.gitignore` para el dataset.
> Por defecto sí se suben para que el trabajo sea reproducible. Decídelo con tu equipo.
