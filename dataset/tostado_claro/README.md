# Clase: `tostado_claro`

Coloca aquí las imágenes de granos con **tostado claro** (light roast):
color canela / marrón claro, superficie **seca** (sin aceite), aroma más ácido.

- **Mínimo 30 imágenes.**
- Varía la **iluminación** (luz natural, luz cálida, sombra).
- Varía el **fondo** (mesa clara, mesa oscura, mano, tela).
- Varía el **ángulo** y la **distancia**.

> ⚠️ El tostado claro puede confundirse con el `tostado_medio`. Captura
> ejemplos claramente diferenciados para ayudar al modelo a separar las clases.
