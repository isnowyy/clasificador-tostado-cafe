# Clase: `tostado_medio`

Coloca aquí las imágenes de granos con **tostado medio** (medium roast):
marrón intermedio, superficie casi seca o con ligerísimo brillo, es el punto
más común para consumo en Colombia.

- **Mínimo 30 imágenes.**
- Varía la **iluminación** (luz natural, luz cálida, sombra).
- Varía el **fondo** (mesa clara, mesa oscura, mano, tela).
- Varía el **ángulo** y la **distancia**.

> ⚠️ Es la clase que más se confunde con `tostado_claro` y `tostado_oscuro`.
> Cuantos más ejemplos variados y bien iluminados, mejor separación aprenderá la red.
